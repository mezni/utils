# BorneMap

BorneMap is a geospatial EV charging discovery platform built for Tunisia. Its mission is to give EV drivers a fast, accurate, and visually rich way to discover and evaluate charging stations — while giving companies, operators, and administrators the tools to manage infrastructure data and monitor platform health.
