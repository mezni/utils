## API Reference

### Health

```
GET /api/v1/health
Response 200: { "status": "ok", "service": "admin-service", "version": "1.0.0" }
```

### Partners — `/api/v1/partners`

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/v1/partners` | Create partner |

| GET | `/api/v1/partners` | List partners (paginated, searchable) |
| PUT | `/api/v1/partners/{partner_id}` | Update partner |

## Business Rules

### Identity
- Entity IDs: `OPR-`/`STA-`/`CHG-` + nanoid(12) lowercase alphanumeric
- Audit: `created_by_uuid` and `updated_by_uuid` are UUID only

### Soft Delete
- All delete endpoints: `UPDATE ... SET deleted_at = NOW()`
- Never `DELETE FROM ...`
- All list/get endpoints filter: `deleted_at IS NULL`

### Pagination
| Parameter | Default | Max |
|-----------|---------|-----|
| `page` | 1 | — |
| `per_page` | 20 | 100 |

### Validation
- Partner `partner_type`: must be `INDIVIDUAL` or `COMPANY`
- Station: requires `name`, `lat` (-90..90), `lon` (-180..180)
- Charger: `count_available >= 0`, `count_total >= 1`, `count_total >= count_available`
