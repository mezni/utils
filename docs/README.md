# BorneMap Docs

## Purpose
This directory holds the architecture, planning, and project-tracking source of truth for BorneMap.

## Canonical Documents
- `constitution.md` - permanent product and architecture rules
- `implementation-plan.md` - MVP progression and scope
- `glossary.md` - project vocabulary
- `out-of-scope-registry.md` - explicit exclusions by MVP

## Project Tracking
- `project/decisions.md` - plan changes and rationale
- `project/backlog.md` - deferred work
- `project/bugs.md` - tracked bugs
- `project/phases/` - MVP phase status files
- `project/sprints/` - sprint plans and outcomes

## Reference Areas
- `api/` - API contracts and endpoint notes
- `schema/` - database and data model notes
- `design/` - design system references
- `ops/` - local dev and operational guidance
- `testing/` - test strategy and smoke checks
- `guides/` - onboarding and contributor guides
- `adr/` - architecture decision records
