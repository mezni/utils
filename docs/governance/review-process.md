# REVIEW PROCESS

---

## 1. Code Review Requirements

All changes MUST pass:

- architecture validation
- API contract validation
- identity compliance check
- layering compliance check

---

## 2. Review Levels

### Level 1 — Syntax Review
- correctness
- compilation safety

### Level 2 — Architecture Review
- Clean Architecture compliance
- dependency rules

### Level 3 — System Review
- consistency with Constitution
- epic alignment

---

## 3. Approval Rule

No change is valid without:
- at least 1 architecture approval
- compliance checklist pass
