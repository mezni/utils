# ERROR TAXONOMY

---

## 1. Standard Error Format

{
  "code": "ERROR_CODE",
  "message": "description"
}

---

## 2. Standard Error Codes

- VALIDATION_ERROR
- NOT_FOUND
- CONFLICT
- INTERNAL_ERROR
- DB_ERROR

---

## 3. Rules

- errors MUST be machine-readable
- errors MUST be stable across versions
