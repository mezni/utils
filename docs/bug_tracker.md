## Bug report template

When reporting a new bug, use this format:

```markdown
### BUG-NNN: [Short description]

**Severity:** Critical / High / Medium / Low
**Found:** MVP-N / Date
**Status:** Open / In progress / Fixed / Won't fix

**Environment:**
- Service/App: [e.g. driver-service, mobile-driver]
- Commit: [git hash]
- Data state: [e.g. fresh DB, after migration 005]

**Steps to reproduce:**
1. [Step 1]
2. [Step 2]
3. [Step 3]

**Expected:** [What should happen]

**Actual:** [What actually happens]

**Logs/screenshots:**
```
[Relevant logs or error output]
```

**Root cause analysis:**
[What caused the bug]

**Fix:**
[How it was fixed, or proposed fix]

**Tests added:**
- [ ] Regression test added
- [ ] Existing tests pass
```
