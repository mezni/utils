# Quickstart: Admin Service (Sprint 1.1)

**Date**: 2026-06-19 | **Phase**: 1 — Design & Contracts

## Prerequisites

- Docker & Docker Compose
- Rust toolchain (stable, 1.70+)
- Node.js 18+ & pnpm
- PostgreSQL 16 with PostGIS extension (provided via docker-compose)

## Setup

### 1. Infrastructure

```bash
# Start PostgreSQL, Traefik, and Redis
docker-compose -f infrastructure/docker/docker-compose.dev.yml up -d postgres traefik
```

### 2. Database

```bash
# Run migrations
cd services/admin-service
cargo sqlx migrate run

# Verify schema
psql -h localhost -U bornemap -d platform_db -c "\dn"  # Should show 'inventory'
```

### 3. Backend (admin-service)

```bash
cd services/admin-service

# Build and run
cargo run -- --port 3002

# Verify health
curl http://localhost:3002/health
# → {"status":"healthy","service":"admin-service","version":"1.0.0"}
```

### 4. API Client Generation

```bash
# Generate TypeScript client from OpenAPI spec
cd apps/dashboard
npx openapi-generator -i ../../api/openapi/admin.yaml -o src/lib/api-client
```

### 5. Frontend (Dashboard)

```bash
cd apps/dashboard

# Install dependencies
pnpm install

# Start dev server
pnpm dev
```

### 6. CI Validator (speckit-lint)

```bash
cd speckit/speckit-lint
cargo build --release
./target/release/speckit-lint --path ../../
```

## Verification
