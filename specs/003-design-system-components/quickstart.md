# Quickstart: Design System & Components

## Prerequisites

- Node.js 20+
- pnpm 9+ (`npm install -g pnpm`)
- TypeScript 5.5+
- Expo CLI (`npx expo`)

## Setup

```bash
# 1. Install dependencies at workspace root
cd source/front
pnpm install

# 2. Build tokens package
pnpm --filter @bornemap/tokens build

# 3. Build UI components package
pnpm --filter @bornemap/ui build

# 4. Run type checking across all packages
pnpm -r typecheck
```

## Package Scripts

### @bornemap/tokens

```bash
cd source/front/packages/tokens
pnpm build        # Build ESM output
pnpm typecheck    # TypeScript strict check
pnpm test         # Run token tests
pnpm lint         # ESLint
```

### @bornemap/ui

```bash
cd source/front/packages/ui
pnpm build        # Build ESM output
pnpm typecheck    # TypeScript strict check
pnpm test         # Run component tests (Jest + RNTL)
pnpm lint         # ESLint
pnpm storybook    # Start Storybook dev server
```

## Testing

```bash
# Run all tests in the workspace
pnpm -r test

# Run with coverage
pnpm -r test -- --coverage

# Visual regression (Chromatic)
pnpm chromatic
```

## Token Generation

If you modify `design-system/bornemap/MASTER.md`, regenerate TypeScript tokens:

```bash
pnpm --filter @bornemap/tokens generate
```

This parses the MASTER.md tables and rewrites the `src/*.ts` files.

## Package Dependencies

```
@bornemap/tokens  ← zero runtime deps
@bornemap/ui      ← @bornemap/tokens, react, react-native
```

Both are workspace packages under `source/front/packages/`. Phase 4 apps consume them via `"@bornemap/*": "workspace:*"`.
