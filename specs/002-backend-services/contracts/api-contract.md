# API Contract: Backend Services

## Base URL

- Driver-service: `http://localhost:8080`
- Admin-service: `http://localhost:8081`

All API endpoints prefixed `/api/v1/`. Health check at `/health`.

## Common Headers

| Header | Required | Description |
|--------|----------|-------------|
| Content-Type | Yes | `application/json` |
| X-Request-Id | Auto | Generated by server, returned in response |

## Error Response Shape (FR-014)

```json
{
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable description"
  }
}
```

With field-level details (validation errors):

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed",
    "details": [
      { "field": "name", "message": "Station name is required" },
      { "field": "lat", "message": "Latitude must be between -90 and 90" }
    ]
  }
}
```

### Error Codes

| HTTP | Code | When |
|------|------|------|
| 400 | BAD_REQUEST | Malformed request, invalid JSON |
| 400 | VALIDATION_ERROR | Field-level validation failures |
| 404 | NOT_FOUND | Resource not found |
| 409 | CONFLICT | Resource conflict (e.g., duplicate name) |
| 500 | INTERNAL_ERROR | Unexpected server error |

## Health Check

### GET /health

**Response 200**:
```json
{
  "status": "ok",

  "database": "connected",
  "version": "0.1.0",
  "uptime_secs": 42
```

```json
  "database": "disconnected",
```

## Driver-Service Endpoints

### List Stations

**GET /api/v1/stations?page=1&per_page=20**

Query parameters:
- `page` (int, default 1, min 1) — page number
- `per_page` (int, default 20, min 1, max 100) — items per page

**Response 200**:
```json
{
  "data": [
    {
      "id": "STA-tunis-centre",
      "name": "TotalEnergies Tunis Centre",
      "address": "Avenue Habib Bourguiba, Tunis",
      "lat": 36.7995,
      "lng": 10.1806,
      "status": "available",
      "opening_hours": "06:00-23:00",
      "partner_id": "PRT-totalenergies-tn",
      "chargers": [
        {
          "id": "CHR-tc-ccs2-1",
          "type": "CCS2",
          "power_kw": 150.0,
          "status": "available",
          "price_per_kwh": 0.45
        }
      ]
    }
  ],
  "total": 5,
  "page": 1,
  "per_page": 20
}
```

**Response 200 (empty)**:
```json
{
  "data": [],
  "total": 0,
  "page": 1,
  "per_page": 20
}
```

### Nearby Stations

**GET /api/v1/stations/nearby?lat=36.8&lng=10.18&radius=10**

Query parameters:
- `lat` (float, required, range [-90, 90])
- `lng` (float, required, range [-180, 180])
- `radius` (float, required, min 0.1, max 100) — radius in kilometers

**Response 200**:
```json
{
  "data": [
    {
      "id": "STA-tunis-centre",
      "name": "TotalEnergies Tunis Centre",
      "address": "Avenue Habib Bourguiba, Tunis",
      "lat": 36.7995,
      "lng": 10.1806,
      "status": "available",
      "opening_hours": "06:00-23:00",
      "partner_id": "PRT-totalenergies-tn",
      "distance_km": 0.5,
      "chargers": [
        {
          "id": "CHR-tc-ccs2-1",
          "type": "CCS2",
          "power_kw": 150.0,
          "status": "available",
          "price_per_kwh": 0.45
        }
      ]
    }
  ],
  "total": 3
}
```

**Response 400 (invalid lat)**:
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed",
    "details": [
      { "field": "lat", "message": "Latitude must be between -90 and 90" }
    ]
  }
}
```

### Station Detail

**GET /api/v1/stations/{id}**

**Response 404**:
```json

    "code": "NOT_FOUND",
```

## Admin-Service Endpoints

### Create Station

**POST /api/v1/stations**

```json
{
  "name": "New Station Tunis",
  "address": "123 Avenue de Carthage, Tunis",
  "lat": 36.8123,
  "lng": 10.1456,
  "partner_id": "PRT-totalenergies-tn",
  "opening_hours": "06:00-23:00",
  "chargers": [
    {
      "type": "CCS2",
      "power_kw": 150,
      "price_per_kwh": 0.45
    },
    {
      "type": "Type2",
      "power_kw": 22,
      "price_per_kwh": 0.30
    }
  ]
}
```

**Response 201**: Full station object with generated `id` and chargers with generated charger `id`s.

```json
{

  "name": "New Station Tunis",

  "partner_id": "PRT-totalenergies-tn",
  "created_at": "2026-06-11T12:00:00Z",
  "chargers": [
    {
      "id": "CHR-yJv3F6kfLz2WxP9Qr8AbC",
      "type": "CCS2",
      "power_kw": 150.0,
      "status": "offline",
      "price_per_kwh": 0.45
    },
    {
      "id": "CHR-mN9oP8qR7sT6uV5wX4yZ3",
      "type": "Type2",
      "power_kw": 22.0,
      "status": "offline",
      "price_per_kwh": 0.30
```

```json
}
```

**Response 400 (invalid partner)**:
```json
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Partner not found: PRT-nonexistent"
  }
}
```

### Update Station

**PUT /api/v1/stations/{id}**

Partial update — only provided fields are changed.

```json
{
  "name": "Updated Station Name",
  "status": "available"
}
```

**Response 200**: Full updated station object.

**Response 404**: Standard NOT_FOUND error.

---

### Soft-Delete Station

**DELETE /api/v1/stations/{id}**

**Response 204**: No content.

**Response 404**: Standard NOT_FOUND error.

---

### Ingest Event

**POST /api/v1/events**

```json
{
  "event_type": "station_viewed",
  "session_id": "sess-abc-123",
  "user_id": "USR-user-456",
  "occurred_at": "2026-06-11T12:00:00Z",
  "payload": {
    "station_id": "STA-tunis-centre"
  }
}
```

**Response 201**:
```json
{
  "id": 42,
  "event_type": "station_viewed",
  "session_id": "sess-abc-123",
  "occurred_at": "2026-06-11T12:00:00Z",
  "ingested_at": "2026-06-11T12:00:01Z"
}
```

**Response 400 (missing required field)**:
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed",
    "details": [
      { "field": "event_type", "message": "Event type is required" }
    ]
  }
}
```

### Ingest Batch Events

**POST /api/v1/events/batch**

```json
{
  "events": [
    {
      "event_type": "station_viewed",
      "session_id": "sess-abc-123",
      "occurred_at": "2026-06-11T12:00:00Z",
      "payload": { "station_id": "STA-tunis-centre" }
    },
    {
      "event_type": "search_performed",
      "session_id": "sess-abc-123",
      "occurred_at": "2026-06-11T12:00:05Z",
      "payload": { "query": "Sfax" }
    }
  ]
}
```

**Response 201**:
```json
{
  "ingested": 2,
  "message": "Successfully ingested 2 events"
}
```

**Response 400 (batch exceeds 100)**:
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Batch size exceeds maximum of 100 events"
  }
}
```

**Response 400 (validation failure — all-or-nothing)**:
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Batch validation failed — 0 events ingested",
    "details": [
      { "field": "events[2].event_type", "message": "Event type is required" },
      { "field": "events[5].occurred_at", "message": "Occurred at is required" }
    ]
  }
}
```
