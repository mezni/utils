# Implementation Plan: Mobile Driver App — Map Discovery

**Branch**: `010-mobile-driver-app` | **Date**: 2026-05-26 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/006-mobile-driver-app/spec.md`

## Summary

Build an Expo-managed React Native mobile app that lets EV drivers discover nearby charging stations on an interactive map. The app uses the existing `/api/v1/stations/nearby` endpoint (made publicly accessible), displays station markers with clustering, and provides a bottom sheet with station/charger details and one-tap navigation.

## Technical Context

**Language/Version**: TypeScript 5.x, Expo SDK 51 (locked per constitution)

**Primary Dependencies**: expo-router, react-native-maps, expo-location, @gorhom/bottom-sheet, react-native-reanimated, react-native-gesture-handler, expo-haptics, @react-native-async-storage/async-storage

**Storage**: None (app is real-time discovery — no persistent local data except radius preference via AsyncStorage)

**Testing**: `pnpm -r type-check`, `pnpm -r lint`, `pnpm -r build`; Expo Go preview on physical device

**Target Platform**: iOS 15+ / Android 12+ via Expo Go (managed workflow — no eject, no prebuild)

**Project Type**: Mobile app (React Native via Expo)

**Performance Goals**: Nearby stations visible within 5 seconds of launch (SC-001); bottom sheet opens in under 500ms (SC-002)

**Constraints**: Managed Expo workflow (no native code); 20km default radius; LIMIT 50 hard cap; `is_test = true` excluded from all results; no app accounts/registration

**Scale/Scope**: MVP0 — anonymous driver discovery only. Charging sessions, reviews, saved stations, push notifications are explicitly out of scope.
